Compatibility and specs

Anti-Bar beside Wizzly

Quit Wizzly before launching Anti-Bar so Alt + Space and screen edges do not collide.

Windows build tools

Requires Node 22+, Rust, and Edge WebView2, plus MSVC Build Tools for NSIS packaging.

Anti-Bar storage and LRCLIB

Settings and clipboard stay on disk. Only song metadata queries lrclib.net when enabled.

Opt-in Windows taskbar sync

Taskbar hiding and Start key hooking stay off until enabled in Anti-Bar Settings.
